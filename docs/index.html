Find what is big

The scan reads folders in parallel and shows its progress as it goes. Three views then show you where the space went.

Size-sorted treeEvery folder opens with its largest items first. A bar shows each item's share of its parent, next to its size and file count.
TreemapEach file is a rectangle sized by its bytes and colored by type: video, images, archives, programs. Double-click a folder to zoom in.
Largest filesThe 500 biggest files under the folder you are viewing. Double-click one to find it in the treemap.
Any drive or folderOne click per drive, or browse to a folder. You can also pass a path on the command line.
Keyboard friendly↑ ↓ select, ← → collapse or expand, Enter zoom in, Backspace zoom out.
Honest numbersSymlinks and junctions are not followed, so nothing is counted twice. Folders it can't read are marked.

See the disk in 3D

A Next.js studio on your machine draws the scan as an explosion diagram, nested rings, a block city, and file-type columns.

ExplosionThe folder splits into pieces. A slider pulls the pieces apart, and leader lines run back to the hub.
RingsEach ring is the inside of the ring it sits on. Click a folder to open it.
CityFootprint and height follow the bytes, with smaller blocks for what is inside.
File typesColumns for video, images, programs, archives, and the other kinds of files.

From the web folder, run npm install and npm run dev, then open http://localhost:3000. cargo run --bin studio opens that studio in a Rust window. The Start menu item Disk Usage Analyzer 3D, or web\launch.cmd, opens the built app at http://127.0.0.1:3847. Folders and files can go to the Recycle Bin or be deleted permanently. Uninstall starts a program's own uninstaller.

Clean up without leaving

Many analyzers only show you the problem. Here you right-click the file or folder and remove it on the spot.

Recycle Bin firstDel moves the item to the Recycle Bin, so you can get it back later.
Or gone for goodShift+Del deletes permanently, after a warning that it can't be undone. Read-only files are handled too.
Always confirmedA dialog shows the name, path and size first. Sizes update right away, and a running total shows the space you freed.

Run it

You need Rust to build it. On Windows you also need the MSVC C++ build tools. Everything else is in this repository.

Build

From source

Clone the repository and build an optimized program.

git clone https://github.com/ktsoaela/Disck-Usage-Analyzer
cd Disck-Usage-Analyzer
cargo build --release
Windows

Start scanning

Open the app, or give it a folder to scan straight away. Run it as administrator to include system folders.

target\release\disk-usage-analyzer.exe
target\release\disk-usage-analyzer.exe "D:\"
